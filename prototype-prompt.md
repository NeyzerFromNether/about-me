# 🏭 Промпт: Прототип системы управления складом и производством

## Контекст
Компания производит молочную продукцию: молоко, кефир, сметана, творог, сыры, йогурты, масло. Есть склад сырья, производственный цех, склад готовой продукции. Нужен лёгкий веб-прототип для управления ключевыми процессами.

---

## 📦 Что должно быть в прототипе

### 1. Дашборд (главный экран)
- Карточки: всего товаров, просрочено, отгружено сегодня, активные заказы
- График поступлений/отгрузок за последние 7 дней (простой canvas или css-бары)
- Список из 3-5 критических уведомлений (истекающие сроки, низкие остатки)

### 2. Склад (инвентарь)
- Таблица всех товаров: название, категория, количество, срок годности, зона, температура
- Поиск по названию и фильтр по категории/зоне
- Цветовая индикация: зелёный (норма), жёлтый (≤7 дней), красный (≤2 дня или просрочен)
- Кнопка «Списать» у каждой строки
- Возможность добавить новый товар (форма: название, категория, зона, кол-во, дата производства, срок хранения дней, температура)

### 3. Приёмка
- Форма с полями: поставщик, товар, категория, зона хранения, количество, дата производства, срок годности, температура
- Автоматическая генерация ID партии (формат: BAT-20260731-XXXX)
- После приёмки товар появляется в таблице склада
- История последних 5 приёмок

### 4. Отгрузка
- Список товаров, доступных к отгрузке
- Выбор товара → указать количество → кнопка «Отгрузить»
- Отгруженный товар списывается со склада
- Лог отгрузок: дата, время, товар, количество, кому

### 5. Производство
- Простая форма: из какого сырья (выпадающий список из склада) → какой продукт на выходе
- Указать: сколько сырья потрачено, сколько продукта получено, дата производства, срок хранения
- После создания — сырьё списывается со склада, продукт добавляется
- Лог последних производственных циклов

### 6. Зоны хранения (мониторинг температуры)
- 4 зоны: холодный склад A (+2…+6°C), холодный B (+2…+6°C), морозильник (-18…-24°C), сухой склад (+15…+25°C)
- Для каждой зоны: текущая t°C (симуляция — плавное случайное колебание ±1.5°C каждые 3 секунды), статус (норма/внимание/тревога), количество позиций
- Карточка зоны подсвечивается красным при выходе за пределы

## 🧱 Технические требования

### Стек
- **Один HTML-файл** (можно разбить на .html/.css/.js, но без бэкенда)
- **Vanilla JS** (без React/Vue/фреймворков)
- **CSS**: современный, тёмная тема, вдохновение — macOS/Notion/Vercel
- **Хранение данных**: `localStorage` (ключ `warehouse_proto`)

### Данные (localStorage)
```js
// Структура одного товара
{
  id: "BAT-20260731-A3F2",
  name: "Молоко пастеризованное 3.2%",
  category: "Молочная продукция",
  zone: "Холодный склад A",
  qty: 450,                        // количество (шт/кг/л)
  produced: "2026-07-28",          // дата производства
  expiry: "2026-08-04",            // срок годности
  temp: 4,                         // рекомендуемая t°C
  supplier: "Ферма Заря",
  type: "raw" | "finished",        // сырьё или готовая продукция
}
```

### Навигация
- Боковая панель (sidebar) слева с иконками и названиями вкладок
- На мобильных — нижняя панель с иконками
- Текущая вкладка подсвечивается

### Внешний вид
- Тёмная тема: фон `#0d1117`, карточки `#161b22`, текст `#e6edf3`
- Акцентный цвет: синий `#58a6ff` или зелёный `#3fb950`
- Скругления: 8-12px
- Шрифт: системный (Inter/-apple-system)
- При наведении на строки таблицы — лёгкое подсвечивание
- Анимации: fadeIn для модалок/табов, плавные переходы цвета у алертов

### Заглушки (демо-данные)
При первом запуске (если localStorage пуст) — загрузить 10-12 товаров:
- 4 молочных продукта (молоко, кефир, творог, сметана)
- 2 сыра
- 1 масло
- 2 сырья (сырое молоко, закваска)
- 1 упаковка
- У разных товаров разные зоны, сроки (от 1 до 60 дней), поставщики

### Алерты и уведомления
- Если срок ≤ 2 дня: красная плашка «СРОЧНО: [товар] истекает [дата]»
- Если товара < 10 шт: жёлтая плашка «Низкий остаток: [товар] — [кол-во] шт»
- Toast-уведомления при действиях (приёмка, списание, отгрузка) — всплывают справа снизу на 2 секунды
- Алерты показываются на дашборде и дублируются цветом в таблице

## 🎯 На выходе
Один или несколько файлов, которые открываются в браузере без сервера. Полноценный прототип: можно принимать товар, отслеживать сроки, списывать, отгружать, мониторить температуры. Все изменения сохраняются в localStorage этого браузера.

## 💡 Подсказки по реализации (если делаешь сам)

```js
// Генератор ID партии
function generateBatchId() {
  const date = new Date().toISOString().split('T')[0].replace(/-/g, '');
  const hex = Math.random().toString(16).slice(2, 6).toUpperCase();
  return `BAT-${date}-${hex}`;
}

// Расчёт дней до истечения
function daysUntilExpiry(expiryDate) {
  return Math.ceil((new Date(expiryDate) - new Date()) / (1000 * 60 * 60 * 24));
}

// Симуляция температуры зоны
function simulateZoneTemp(baseMin, baseMax) {
  const base = (baseMin + baseMax) / 2;
  const noise = (Math.random() - 0.5) * 3;
  return +(base + noise).toFixed(1);
}

// Сохранение / загрузка
const STORAGE_KEY = 'warehouse_proto';
function loadData() { return JSON.parse(localStorage.getItem(STORAGE_KEY)) || seedDemoData(); }
function saveData(data) { localStorage.setItem(STORAGE_KEY, JSON.stringify(data)); }

// Toast
function showToast(message, type = 'success') {
  const toast = document.createElement('div');
  toast.className = `toast toast-${type}`;
  toast.textContent = message;
  document.body.appendChild(toast);
  setTimeout(() => { toast.style.opacity = '0'; setTimeout(() => toast.remove(), 300); }, 2000);
}
```
